THE FIX EXPLAINED (30 SECONDS)
================================================================================

BEFORE (Broken):
  Rust calculated stride as: width × 4 bytes
  Problem: Ignored GPU padding/alignment
  Result: Wrong offsets → pixel data corruption → diagonal stripes

AFTER (Fixed):
  Rust uses: image.stride() from IronRDP decoder
  Benefit: Respects GPU alignment + padding
  Result: Correct offsets → clean pixel data → no artifacts

Additional Flutter fixes:
  • Boundary validation before blit
  • Better error messages
  • Enhanced logging
